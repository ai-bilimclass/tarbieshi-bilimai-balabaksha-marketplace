# Обязательная сборка циклограммы и плана дня

Циклограмму и план дня нельзя создавать произвольным кодом или вручную
собранной таблицей. Используй только
`scripts/build_planning_document.py`: он копирует форму из файла
`Методическое сопровождение для Плагина ДО.docx` и автоматически проверяет
структуру и оформление итогового DOCX.

Перед запуском получи путь к Python через загрузчик зависимостей рабочего
пространства и используй именно этот интерпретатор; системный Python не
используй.

## Формат входного JSON

Обязательное поле `language`: `kk` (қазақша), `ru` (русский) или `en` (English).
Язык распространяется на весь документ: заголовок, реквизиты, дни недели,
названия режимных строк и всё содержимое ячеек. Сборщик переводит служебные
подписи сам; содержимое ячеек и значения реквизитов подавай на выбранном языке.
Исходный шаблон используется только как канонический ключ и порядок строк.

Общие поля: `organization`, `group`, `age`, `period`, `topic`, `value` и
`rows`. Для плана дня также обязательны `day` и `date`.

`rows` — массив в точном порядке режимных строк выбранной формы. Поле `label`
должно дословно совпадать с русским первым столбцом шаблона даже для `kk` и
`en`; в итоговом DOCX оно автоматически отображается на выбранном языке. Дублирующиеся строки
сохраняются как отдельные элементы массива.

Для недельной циклограммы каждый элемент имеет вид:

```json
{
  "label": "Прием детей",
  "days": {
    "Пн": "...",
    "Вт": "...",
    "Ср": "...",
    "Чт": "...",
    "Пт": "..."
  }
}
```

Каждая дневная ячейка недельной циклограммы содержит четыре части в порядке:
`Цель/Мақсат/Goal`, `Задача/Міндет/Task`, `Ход/Барысы/Procedure`,
`Ожидаемый результат/Күтілетін нәтиже/Expected result`. Выбирай четыре
метки одного языка. В части «Ход/Барысы/Procedure» опиши
последовательные действия педагога и детей с материалом; для организованной
деятельности раскрой введение, основное действие и закрепление. Сборщик
отклоняет пропущенные части и чрезмерно краткие формулировки. Увеличение числа
страниц допустимо; не сокращай методическое содержание ради одной страницы.

Для каждой строки «Прогулка» внутри `Ход/Барысы/Procedure` укажи четыре
нумерованные части с новой строки каждая на языке документа: `1.` наблюдение в природе с
познавательным действием, `2.` подвижная игра или упражнение, `3.` труд в
природе, `4.` самостоятельная деятельность детей. Отдельно укажи
`Длительность: 90 минут` / `Ұзақтығы: 90 минут` / `Duration: 90 minutes`
или большее фактическое число минут. Сборщик проверяет порядок частей и
минимальную длительность также для плана дня.

Для плана дня каждый элемент имеет вид:

```json
{
  "label": "Прием детей",
  "content": "..."
}
```

## Команды

Недельная циклограмма:

```powershell
& $PYTHON_BIN scripts/build_planning_document.py --mode weekly --group-type preschool --data input.json --output result.docx
```

План дня:

```powershell
& $PYTHON_BIN scripts/build_planning_document.py --mode daily --group-type preschool --data input.json --output result.docx
```

Для предшкольного класса используй `--group-type preprimary`.

## Неизменяемые свойства

- недельная циклограмма: одна таблица, ровно шесть столбцов;
- план дня: одна таблица, ровно два столбца;
- строки и их порядок берутся только из соответствующей формы исходного
  DOCX;
- шрифт во всём документе — Times New Roman, 12 pt;
- текст и границы таблицы — только чёрные `#000000`;
- цветная заливка ячеек отсутствует;
- строка заголовков повторяется при переносе таблицы;
- каждая секция итогового DOCX имеет альбомную ориентацию (ширина больше высоты);
- если JSON меняет структуру шаблона или проверка оформления не проходит,
  скрипт завершает работу с ошибкой и документ нельзя выдавать пользователю.

Не обходи ошибку скрипта созданием альтернативного DOCX. Исправь входные
данные и повтори сборку.
