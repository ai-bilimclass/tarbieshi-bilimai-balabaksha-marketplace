# Дополнительный XLSX для трёх плановых документов

Применяй только если воспитатель попросил Excel для перспективного плана,
недельной циклограммы или плана дня. Сначала закончи и проверь обязательный
DOCX. XLSX создавай из **этого же готового DOCX**, а не повторной генерацией
педагогического содержания. Передай пользователю оба файла. Дидактический
материал в XLSX не переводится.

На одном листе Excel сохраняй язык документа, реквизиты, все режимные или
помесячные строки, полный текст ячеек и текст после таблицы. Число и порядок
столбцов должны совпадать с Word: 3 для перспективного плана, 6 для
циклограммы, 2 для плана дня. Для перспективного плана месяц в первом столбце
показывай один раз с объединением ячеек на все виды деятельности этого месяца.
Не сокращай подробные задачи или ход работы ради ширины листа.
Для перспективного плана и циклограммы все листы XLSX должны иметь альбомную
ориентацию печати. Это обязательное свойство сохранённого файла, а не только
внешнего вида на экране.

## Сборка

1. Получи пути к Python, Node.js и `node_modules` через загрузчик зависимостей
   рабочего пространства. Используй пакет `@oai/artifact-tool` из
   предоставленного `node_modules`.
2. Создай временную рабочую папку. Скопируй в неё
   `scripts/build_planning_spreadsheet.mjs` и создай в этой папке ссылку
   `node_modules` на предоставленный загрузчиком каталог. На Windows
   используй junction. Не копируй и не меняй сами зависимости.
3. Извлеки содержание проверенного DOCX:

   ```powershell
   & $PYTHON_BIN scripts/extract_planning_docx.py --mode annual --input plan.docx --output-json work/plan.json
   ```

   Для циклограммы используй `--mode weekly`, для плана дня `--mode daily`.
4. Создай XLSX:

   ```powershell
   & $NODE_BIN work/build_planning_spreadsheet.mjs work/plan.json plan.xlsx $PYTHON_BIN scripts/set_xlsx_landscape.py
   ```

   Для перспективного плана и циклограммы последние два аргумента обязательны:
   сборщик установит альбомную ориентацию печати и проверит её до сообщения
   об успешном сохранении. Для плана дня допустимы только первые два аргумента.

5. Повторно открой XLSX и сверь количество строк, столбцов, первый и последний
   содержательные элементы, месяц или дни недели и весь текст каждой ячейки
   с DOCX. Проверь читаемость длинных ячеек в Excel. Если длина ячейки
   превышает предел Excel 32767 символов, скрипт остановится; не урезай
   содержание без согласования с пользователем.
   Для перспективного плана и циклограммы дополнительно повторно проверь
   `page_setup.orientation == landscape` у каждого сохранённого листа.

XLSX — редактируемая дополнительная форма того же плана. DOCX остаётся
обязательным исходником и сохраняет все требования навыка к оформлению.
