# Структура редактируемого недельного комплекта

## Разделы Word

Документ содержит ровно три секции Word:

1. книжная ориентация — обложка и резюме;
2. альбомная ориентация — пятидневная циклограмма;
3. книжная ориентация — все печатные и методические материалы.

В каждой секции используй A4, колонтитул и номер страницы. Переходы между крупными блоками выполняй разрывами страниц, не пустыми абзацами.

## Последовательность содержимого

Обложка → резюме → циклограмма → карточки → парные/пространственные задания → логические карточки → ключи → графомоторика → вырезные полоски → раскраска → письменные творческие алгоритмы → четырёхкадровые схемы → итоговый сценарий → дополнительные материалы.

Циклограмма — настоящая таблица Word. Карточки и кадры можно компоновать таблицами без автоподбора ширины, с согласованными ширинами ячеек и рамками. Таблицы не должны превращать длинную методическую прозу в тесные ячейки.

## Редактируемость

Стили заголовков, обычный текст, инструкции, подписи, ключи и графомоторные линии остаются редактируемыми. Изображениями могут быть только иллюстрации. Не вставляй снимки страниц и не делай PDF исходным форматом.

## Контроль перед выдачей

Повторно открой DOCX через `python-docx`, проверь три секции, ориентации, таблицы, абзацы, встроенные изображения и отсутствие внешних ссылок на локальные картинки. Затем отрендери все страницы штатным `render_docx.py`, просмотри каждый PNG и после любых исправлений повтори цикл.
