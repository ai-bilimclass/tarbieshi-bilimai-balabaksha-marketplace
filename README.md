# Tarbieshi BilimAI Balabaksha

Плагин для воспитателей дошкольных организаций. Подготовка перспективного плана, недельной циклограммы, плана дня, дидактических материалов и методические консультации.

## Подключение

На компьютере с установленным Codex CLI выполните:

```powershell
codex plugin marketplace add https://github.com/ai-bilimclass/tarbieshi-bilimai-balabaksha-marketplace.git
```

Затем откройте каталог плагинов в поддерживаемом настольном приложении, выберите источник Tarbieshi BilimAI Balabaksha и установите плагин.

## Обновление источника

```powershell
codex plugin marketplace upgrade tarbieshi-bilimai-balabaksha
```

## Состав

- `.agents/plugins/marketplace.json` — каталог marketplace.
- `plugins/tarbieshi-bilimai-balabaksha/` — полный исходный пакет плагина.
- Подробнее о работе плагина: [README плагина](plugins/tarbieshi-bilimai-balabaksha/README.md).

Версия пакета: 0.1.3+codex.20261001.
